## Install

```bash
./install.sh --modules skills
```

Run from the repository root. No Homebrew packages are installed by this module.

## Setup

The installer also selects omp. `project-scaffold` defines project structure and migration rules; `skill-improve` updates skills from user feedback. Read their `SKILL.md` files before use: skill-improve includes automatic Git commit and push instructions. Third-party skills are linked below, not bundled.
