# codexbar

[English](README.md) | [简体中文](README.zh-CN.md)

AI account usage in the menu bar.

## Install

```bash
./install.sh --modules codexbar
```

Run from the repository root. Homebrew packages: `codexbar`.

## Files and destinations

| Source | Destination |
|---|---|
| [`home/.config/codexbar/config.json`](home/.config/codexbar/config.json) | `~/.config/codexbar/config.json` |

## Setup

Open CodexBar and sign in to the providers you use. `config.json` selects providers but contains no account credentials. Disable providers you do not use.
