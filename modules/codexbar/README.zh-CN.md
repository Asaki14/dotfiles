# codexbar

[English](README.md) | [简体中文](README.zh-CN.md)

菜单栏 AI 账户用量。

## 安装

```bash
./install.sh --modules codexbar
```

在仓库根目录运行。Homebrew 依赖：`codexbar`。

## 文件与链接目标

| 源文件 | 目标 |
|---|---|
| [`home/.config/codexbar/config.json`](home/.config/codexbar/config.json) | `~/.config/codexbar/config.json` |

## 配置

打开 CodexBar 并登录所需服务。`config.json` 选择服务，不包含账户凭证。关闭不使用的服务。
