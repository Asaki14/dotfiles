# linearmouse

[English](README.md) | [简体中文](README.zh-CN.md)

鼠标配置。

## 安装

```bash
./install.sh --modules linearmouse
```

在仓库根目录运行。Homebrew 依赖：`linearmouse`。

## 文件与链接目标

| 源文件 | 目标 |
|---|---|
| [`home/.config/linearmouse/linearmouse.json`](home/.config/linearmouse/linearmouse.json) | `~/.config/linearmouse/linearmouse.json` |

## 配置

打开 LinearMouse 并授予 macOS 请求的权限。按自己的鼠标检查 `linearmouse.json` 中的设备匹配与指针设置。
