# linearmouse

[English](README.md) | [简体中文](README.zh-CN.md)

Mouse configuration.

## Install

```bash
./install.sh --modules linearmouse
```

Run from the repository root. Homebrew packages: `linearmouse`.

## Files and destinations

| Source | Destination |
|---|---|
| [`home/.config/linearmouse/linearmouse.json`](home/.config/linearmouse/linearmouse.json) | `~/.config/linearmouse/linearmouse.json` |

## Setup

Open LinearMouse and grant the permissions macOS requests. Review device-specific matching and pointer settings in `linearmouse.json` for your mouse.
