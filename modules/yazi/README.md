# yazi

[English](README.md) | [简体中文](README.zh-CN.md)

File management and previews.

## Install

```bash
./install.sh --modules yazi
```

Run from the repository root. Homebrew packages: `yazi`, `ffmpeg`, `sevenzip`, `poppler`, `fd`, `ripgrep`, `fzf`, `zoxide`, `imagemagick`, `resvg`.

## Files and destinations

| Source | Destination |
|---|---|
| [`home/.config/yazi/keymap.toml`](home/.config/yazi/keymap.toml) | `~/.config/yazi/keymap.toml` |
| [`home/.config/yazi/theme.toml`](home/.config/yazi/theme.toml) | `~/.config/yazi/theme.toml` |
| [`home/.config/yazi/yazi.toml`](home/.config/yazi/yazi.toml) | `~/.config/yazi/yazi.toml` |

## Setup

The installer adds smart-enter and compress with `ya pkg`. Enter opens a file or directory, `e` opens Neovim, `c p` copies a path and `c a` compresses a selection. Install the nvim module or change the opener. The configured `omacosy` flavor is generated by the omacosy module; install it or choose another flavor in `theme.toml`.

- [smart-enter (yazi-rs)](https://github.com/yazi-rs/plugins/tree/main/smart-enter.yazi)
- [compress (KKV9)](https://github.com/KKV9/compress.yazi)
